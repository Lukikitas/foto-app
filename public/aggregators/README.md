# Identidad de plataformas

Iconos publicados por los desarrolladores en sus fichas de App Store de Argentina, consultados el 11 de octubre de 2026. Los archivos se usan sin modificaciones como identidad visual de las plataformas dentro de la app.

- PedidosYa / Pedidos Ya S.A.: https://apps.apple.com/ar/app/id490099807
- Rappi / Grability Inc.: https://apps.apple.com/ar/app/id984044296
- Mercado Pago / MercadoLibre S.A.: https://apps.apple.com/ar/app/id925436649

Rappi Turbo utiliza el icono de Rappi con un indicador de rayo y su nombre explícito, para distinguir ambas cuentas. El indicador es interfaz de la app; no pretende ser otro logotipo oficial.

sources.json conserva los enlaces a cada imagen y a la ficha del desarrollador. scripts/fetch-aggregator-logos.mjs permite volver a consultar las mismas fichas.
